# مُجهّز صفحة الأسئلة (النسخة المحسّنة)

تطبيق ويب يحوّل صور أوراق الامتحان إلى ملف Word منسّق — كل صورة في صفحة واحدة مكتملة.

## الجديد في هذه النسخة
- إصلاح تصدير Word: ملف .docx حقيقي، كل صفحة في Section مستقل بنفس الخط والهوامش وحجم الصفحة المضبوطة.
- أزرار تحكم بكل عنصر: ✏️ تعديل • ▲▼ تحريك • ✕ حذف (ظاهرة دائماً على شاشات اللمس).
- لوحة إعدادات كاملة: حجم الصفحة (A4/A5/Letter/Legal)، نوع الخط، حجم الخط، تباعد الأسطر، الهوامش الأربعة، الإطار الزخرفي، نص التذييل.
- ضغط الصورة تلقائياً قبل التحليل (أسرع وأخف على الهاتف).
- إصلاح اسم نموذج Gemini في دالة التحليل.
- تصميم مريح لهواتف Android (أزرار كبيرة، صفحة بحجمها الحقيقي مع تمرير أفقي).

## النشر على Netlify
1. ارفع المجلد إلى Netlify (Drag & Drop أو Git).
2. في Site settings → Environment variables أضف: `GEMINI_API_KEY` = مفتاحك من Google AI Studio.
3. (اختياري) أضف `APP_SECRET` وضع نفس القيمة في المتغير `APP_SECRET` داخل index.html.

كل شيء يعمل بعدها مباشرة: التقاط الصورة → تحليل → مراجعة وتعديل → تحميل Word.
